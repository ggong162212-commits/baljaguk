# 발자국 🐾

유기견·유기묘 봉사 동아리 **발자국**의 부원 모집 폼 + 운영진 관리 사이트.
모바일에서 쓰는 것을 기준으로 만들었습니다. 서버 없이 정적 파일만으로 동작해요.

| 화면 | 주소 | 누가 |
|---|---|---|
| 가입 신청 폼 | `index.html` | 신청자 (누구나) |
| 운영진 관리 | `admin.html` | 운영진 (비밀번호) |

두 화면은 주소가 다르지만 같은 데이터를 봅니다. 폼으로 들어온 신청을 운영진 화면에서 **승인하면 구성원 명단에 자동으로 추가**됩니다.

---

## 무엇을 할 수 있나요

**신청자 화면**
- 이름·학번·학과·연락처·지원동기 작성, 입금증 사진 첨부
- 계좌번호 한 번에 복사, 전화번호 자동 하이픈
- 작성 중이던 내용 자동 임시저장 (실수로 나가도 복구)
- 사진 붙여넣기(Ctrl+V)·드래그 첨부, 자동 용량 축소
- 접수 마감 시 안내 문구 자동 표시

**운영진 화면**
- **폼** — 접수 켜기/끄기, 접수 시작·자동 마감 **예약**, 정원 도달 시 자동 마감, 폼 링크·공지 문구 복사
- **가입** — 신청 목록, 입금증 확인, 승인/반려, 대기 건 일괄 승인, 승인 시 회비 자동 장부 기록
- **구성원** — 검색·필터·정렬, 역할(운영진/일반)·상태(활동중/휴면) 관리, 봉사 이력, CSV 내보내기
- **봉사** — 달력에서 날짜를 고르고 그 날의 봉사모임 생성 → 참여한 구성원 체크(봉사 시간까지) → 누적 횟수·이달의 참여왕 자동 집계
- **재정** — 잔액·수입·지출 장부, 월별 조회, CSV 내보내기 *(운영진만 볼 수 있음)*
- **자동 동기화** — 운영진이 각자 폰에서 봐도 신청·봉사·재정 변경이 서로에게 바로 반영돼요 (Supabase Realtime, 안 될 땐 자동 폴링)
- 다크 모드, 전체 데이터 백업(JSON)

잠금을 꺼 두는 동안에는 주소를 아는 사람이 신청자 연락처·입금증·재정을 볼 수 있으니 주소를 운영진끼리만 공유해주세요.

## 실제로 쓰려면 (Supabase 연결, 5분)

여러 운영진이 각자 폰에서 같은 데이터를 보려면 데이터베이스가 필요합니다. 무료로 충분해요.

1. <https://supabase.com> 가입 → **New project** 생성
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 파일 내용을 통째로 붙여넣고 **Run**
3. **Authentication → Users → Add user**  *(비밀번호 없이 들어가더라도 이 계정은 꼭 필요합니다)*
   - Email: `unyoung@baljaguk.club` *(아무 주소나 가능. 4번의 `ADMIN_EMAIL`과 같기만 하면 됩니다)*
   - Password: `260324` *(운영진 페이지에서 입력할 비밀번호)*
   - **Auto Confirm User** 켜기
4. **Project Settings → API** 에서 두 값을 복사해 `assets/config.js` 에 붙여넣기
   ```js
   SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbG...'
   ```

> `anon key`는 공개되어도 되는 키입니다. 데이터 보호는 Supabase의 RLS 정책이 담당해요.
> **신청자(비로그인)는 신청서를 넣을 수만 있고, 다른 사람의 신청·연락처·재정은 조회할 수 없습니다.**

## GitHub Pages로 배포

1. 이 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: `main` / `/ (root)` → Save
3. 1~2분 뒤 주소가 만들어집니다
   - 신청 폼: `https://<계정>.github.io/<저장소>/`
   - 운영진: `https://<계정>.github.io/<저장소>/admin.html`

신청자에게는 앞 주소만 공유하면 됩니다.

## 파일 구조

```
index.html            신청 폼
admin.html            운영진 관리
assets/
  config.js           ← Supabase 주소·키 (여기만 수정하면 됨)
  style.css           디자인 시스템 (라이트·다크)
  icons.js            인라인 SVG 아이콘
  ui.js               토스트·바텀시트·포맷·이미지 축소 등 공통 유틸
  db.js               데이터 계층 (Supabase REST ↔ 체험 모드 자동 전환)
  public.js           신청 폼 로직
  admin.js            운영진 화면 로직
supabase/schema.sql   테이블 · 보안 정책 (한 번만 실행)
```

## 메모

- 입금증 사진은 업로드 전에 브라우저에서 가로세로 1280px로 줄여 저장합니다.
- 비밀번호는 운영진 화면 **설정**에서 바꿀 수 있습니다.
- 체험 모드에서 만든 데이터는 Supabase로 옮겨지지 않습니다. 연결 후 새로 시작해주세요.
